TURN 03 How I handle being wrong

A bot is only as trustworthy as its worst moment.

So I design the error path first. When the system isn’t sure, it gets exactly three moves, in this order.

Miss 1Clarify

“The voice banking flows, or the UPI payment disputes?”Offer options instead of an open question.

Miss 2Rephrase

“I’m best at three things: the work, the process, or getting in touch.”Never repeat the same prompt.

Miss 3Hand off

“This one’s better with a human. I’ve attached your question.”Context goes with the handoff.

The bar at the bottom of the screen follows these rules.
COPY · 08Two options are faster than “Sorry, could you rephrase that?” The user shouldn’t have to guess what the system can understand.
FLOW · 09Asking the same question twice feels like a loop, and a loop feels like a trap. The second attempt changes the framing instead.
FLOW · 10This site acts at 60% confidence. In banking I set the threshold per flow: blocking a card needs far more certainty than checking a balance.
